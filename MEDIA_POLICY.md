# Política de mídia

Código aberto e direito de mídia são camadas diferentes.

## Não redistribuir automaticamente

- obras;
- fotografias;
- identidades/logotipos de clientes sem licença de redistribuição;
- mockups de terceiros;
- arquivos de alta resolução;
- dados internos.

## Site publicado

O site pode exibir ativos autorizados com crédito adequado. A ausência de uma imagem no repositório público é uma decisão de governança, não uma ausência no produto final.
