# portfolio-alessandra

Código e documentação do portfólio profissional de Alessandra de Mattos.

**Foco:** UX/UI, WordPress, front-end aplicado, acessibilidade, QA e documentação.

## Estado

Esta edição de código deriva da candidata **v53**. O site publicado em https://aledmattos.akilidesign.com.br/ usa a v56. Este repositório é uma edição pública de referência da v53 e não uma cópia exata da produção.

## O que demonstra

- arquitetura da informação;
- layout responsivo;
- design system;
- cases expansíveis;
- teclado e foco;
- menu mobile com Escape e retorno de foco;
- `prefers-reduced-motion`;
- QA estrutural;
- separação entre autoria técnica e mídia de clientes.

## Política de mídia

Ativos comerciais e de clientes não são redistribuídos automaticamente neste repositório. Os pontos correspondentes usam guardas de mídia na edição pública do código.

Veja `MEDIA_POLICY.md`.

## Rodar localmente

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.
